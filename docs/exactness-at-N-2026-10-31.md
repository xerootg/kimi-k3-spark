Production evidence: `evidence/c-tree-extra/` (paths below relative to it), plus `evidence/c-tree/ggml/src/ggml-cuda/{ggml-cuda,mmvq}.cu`.

Execution order can expose indexer first.

Top-k index order alone can differ without changing attention: membership is scattered into a positional mask. Boundary membership among visible equal scores matters; masked padding selections do not.
KV extent is max padded used cell across participating streams (llama-kv-cache.cpp:1282); slicing does not shrink it. Physical KV placement/masked NaNs/padding and differing history are outside a per-column proof.
LLAMA_DSA_SHORT_CTX_SKIP=1 is singleton-only when padded KV<=2048; it skips scores and uses identity selection. Disable for clean node-aligned diagnostics; all visible keys still enter attention.
